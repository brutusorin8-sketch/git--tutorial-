The purpose of this repository was initially to get an understanding on how to initialize and manage a local Git repository. I had to collaborate with a colleague as well who would more than likely have access to GitHub. As such, I also had to create, commit, push, and also merge changes by using branches and pull requests. Inconclusion, demonstration of proof of work via Git Hub and documentation was also a requirement.
**Step 1**-(Install Git and create a GitHub account), downloaded Git for windows on my laptop and created a GitHub account.
**Step 2**-(Create a repository), I signed into GitHub looked for a + icon which was found at the upper-right corner. Selected New Repository which then I entered a name and set the visibility to Public for the repository. After completing that I left the options for adding a README, gitignore and the licence was unchecked for the particular setup I then click Create Repository to move on further.
**Step 3**-(Create a Local Git Repository), a folder was created and opened, ITE1100- Tutorial-4. After right clicking and selecting the Git Bash software I enetered "git init" to set the branch as -M, main. Replaced Git name and email address to the more suitable information. Ensure the URL was replaced, ran a command which would've showed if the address was connected using "git remove -v". 
**Step 4**-(Add classmate as a Collaborator), upon accessing GitHub select Settings after finding and selecting Collaborators, I added colleague using his email which I sent the invitation. Upon receivng such, it was accepted.
**Step 5**-(Create a new branch), I returned to my Git Bash folder which I ran a command to create a new branch.
**Step 6**-(adding a new file), using the Notepad text editor I typed the following Python code which would've been ("Orin Brutus"), I would've had to provide those two. The file was saved and named hello.py, checked the git status to ensure it was accurate. 
**Step 7**-(Committing new file), added file to the staging area, which the command would have been git add hello.py. With that, git commit -m was ran and also git status to more than likely know the status.
**Step 8**-(Push the new branch to GitHub), ensured the correct feature branch was active and entered git push -u origin etc. A Git request authentication was shown this allowed the command to add the branch and file.
**Step 9**-(Create a pull request), in GitHub I selected Pull Request and then create a new pull request, set the base branch to main and compare branch to feature etc. Clicked create pull request added a suitable title and it was created. In the reviewers tab, selected colleague as reviewer. 
**Step 10**-(Reviewed and Approved Pull Request), colleague checked and submitted review the Pull Request after confirming everything accurate.
**Step 11**-(Merge new branch into main and or master branch ), clicked Merge Pull Request since everything was accurate and confirmed the merge. Navigate to the repository's main page and selected the main branch and check that hello.py is present.
